Frequently asked questions

Where is my data stored?

By default, on this device only. In Settings → Sync you can switch to All My Devices (iCloud) so portfolio data syncs across iPhone and iPad signed into the same Apple ID with iCloud Drive available.

iCloud sync isn’t updating

  • Confirm you’re signed into iCloud and that iCloud Drive is on.
  • Open Settings → Sync and check Sync Health; try Force Sync Now.
  • Use Show Sync Diagnostics and include that text if you email support.
  • Wait for network connectivity; large conflicts may require choosing cloud vs device data (and typing SYNC for destructive replaces).

How do I back up?

Settings → Backup & Restore → Back Up to File. Optionally enable automated backup reminders and choose a destination folder. Restoring replaces all current portfolio data—confirm carefully.

What is Project Vault?

Set a vault destination and folder name (default Project Vaults). From an application with a linked project folder, you can copy that folder into the vault with sequenced names for archival snapshots.

How does Focus mode work?

In the Sprint Workbench, double-tap an activity. Use play/pause to time work, add notes, and mark the item done. Time feeds Analytics totals.

Can I customize statuses and categories?

Yes. Settings → Pick lists lets you edit lifecycle statuses, sprint statuses, item categories (with SF Symbol names), platforms, and application categories. Use Reorder to change order.

Does the app collect analytics about me?

In-app Analytics are your work-time totals stored with your portfolio. The App does not use third-party tracking or advertising SDKs. See the Privacy Policy.
