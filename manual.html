User Manual

Learn how to track applications, run sprints, capture Focus time, sync with iCloud, and keep durable backups.

Contents

1. Overview

Developer Portfolio is a personal shipping cockpit for Apple-platform developers. It helps you:

  • Maintain a portfolio of apps across lifecycle stages (Ideation → Published → Maintenance).
  • Plan sprints and typed activities (Fix, Enhancement, Idea, Refactor, Research).
  • Execute work in the Sprint Workbench and time deep work in Focus mode.
  • Review time spent in Analytics.
  • Optionally sync via iCloud, export backups, and vault project folders.

The main interface uses four tabs: Applications, Settings, Workbench, and Analytics. On larger iPads, navigation may use a split view; on iPhone, a stack-based layout.

2. Getting started

  1. Launch the app. A short splash screen shows Developer Portfolio — Build. Track. Ship.
  2. Open the Applications tab.
  3. Create your first application (name, summary, status, platforms, category).
  4. Add a sprint, then add activities inside that sprint.
  5. Open the sprint in Workbench to reorder work, run Focus sessions, and mark items done.
  6. Visit Settings to choose theme, storage mode, and backup preferences.
Empty state tip: if you have no apps yet, create one to start planning ideation, creation, testing, and publishing.

3. Applications

Applications are the top-level records in your portfolio.

Create or edit an application

  • Name — product name as you want it listed.
  • Summary — short description of what you’re building.
  • Lifecycle status — defaults include Ideation, Design, Development, Testing, Ready for Review, Published, Maintenance (customizable in Settings).
  • Platforms — e.g. iOS, iPadOS, watchOS, macOS, tvOS, visionOS.
  • Category — e.g. Productivity, Utilities, Business.
  • Version & build — current marketing version and build number.
  • Icon — optional image via the system photo picker.
  • Project folder — link a folder on disk (Files / local storage) so you can open it later or copy it into the Project Vault.

Delete an application

Deleting an application removes its sprints, activities, and associated Focus history from the portfolio. Export a backup first if you might need the data later.

4. Sprints

Each application can contain multiple sprints.

  • Create a sprint with name, version, build, status (Planned, Active, Paused, Complete by default), and start date.
  • Add activities (work items) with a type/category, title, and notes.
  • Mark activities done as you finish them; incomplete items stay visible in the Workbench.
  • Use Hide Completed Sprints in Settings → Display if you want a cleaner list.

Open a sprint in the Workbench to focus on execution for that slice of work.

5. Sprint Workbench

The Workbench is where day-to-day shipping happens.

  1. Select an application and sprint.
  2. Review the activity list. Optionally hide completed items.
  3. Reorder activities to match priority.
  4. Edit notes, change categories, or delete items you no longer need.
  5. Use vault actions (when configured) to snapshot the linked project folder.

On compact devices you’ll navigate via stacks; on regular-width iPads, split navigation keeps context visible.

6. Focus mode

Focus mode turns a single activity into a timed work session.

  • Enter Focus: double-tap an activity in the Workbench.
  • Timer: play to start counting; pause when you step away.
  • Notes: capture decisions or blockers while you work.
  • Done: mark the activity complete when finished.

Recorded sessions contribute to Analytics totals for that app, sprint, and task.

7. Analytics

The Analytics tab aggregates Focus time so you can answer: Where did the hours go?

  • Totals by application
  • Totals by sprint
  • Totals by task / activity

Analytics reflect data stored in your portfolio (device and/or iCloud). They are not sent to a Developer analytics service.

8. Sync & iCloud

Settings → Sync controls where portfolio data lives.

This Device OnlyPortfolio data stays on the current iPhone or iPad.
All My Devices (iCloud)Apps and settings sync across devices using the same Apple ID when iCloud Drive is available.

Useful sync actions

  • Force Sync Now — push/pull promptly when online.
  • Reload All Data from iCloud — replace local portfolio with the cloud copy (destructive to local-only changes).
  • Show Sync Diagnostics — technical status useful for troubleshooting.
  • Sync Health — quick indicator when iCloud mode is on.
Conflicts: If cloud and device data differ at first sync, you’ll choose which set to keep. Replacing iCloud with device data requires typing SYNC to confirm. This can overwrite cloud data—back up first.

If the iCloud container cannot open, confirm you’re signed into iCloud with iCloud Drive enabled.

9. Backup, Restore & Project Vault

Manual backup

Settings → Backup & Restore → Back Up to File exports a JSON backup (schema version 1) including applications and settings.

Restore

Restore from Backup replaces your current portfolio data on this device and, when in iCloud sync mode, affects the synced dataset. The app shows confirmation warnings—read them before proceeding.

Automated backup reminders

  • Enable reminders and choose an interval (days, weeks, or months).
  • Pick a destination folder.
  • Use Run Backup Now when prompted or from settings.
  • Overdue checks run at app launch based on time since the last successful backup.

Project Vault

  • Choose a Vault destination and subfolder name (default Project Vaults).
  • Link a project folder on an application.
  • Copy the folder into the vault; copies use sequenced names so earlier snapshots are preserved.

11. Tips & troubleshooting

  • Ship rhythm: Keep one Active sprint per app you’re actively building; park the rest as Planned or Paused.
  • Review readiness: Move lifecycle status to Ready for Review when TestFlight builds are stabilizing.
  • Before risky sync: Back Up to File, then proceed.
  • Icon tips: Use a simple 1024-style mark; it scales better in lists.
  • Lost work after restore: Restores replace data by design. Keep dated backup files.
  • Still stuck? Visit Support with Sync Diagnostics text and your iOS version.
